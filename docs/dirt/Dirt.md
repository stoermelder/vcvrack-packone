# stoermelder DIRT

DIRT is a simple noise module for polyphonic cables:

- It will add different levels of white noise to each channel
- It will add crosstalk between different channels of the same cable
- It will add different amount of crackle
- It will add pitch shifting defects
- It will add bit crushing defects
- It will add volume dropout defects

Please note: Every instance of DIRT is unique, two modules will not sound the same.
